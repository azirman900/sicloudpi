CLOUD PI
Panduan singkat CLOUD PI

Apa itu CLOUD PI?

CLOUD PI adalah jaringan tambang Pi berbasis cloud — semua proses mining berjalan di server awan kami, bukan di device kamu. Kamu cukup login, aktifkan node, dan pantau hasilnya. HP boleh mati, laptop boleh ditutup — mining tetap jalan 24 jam di awan.

Cara kerja

01

Hubungkan dompet

Masuk pakai 24 kata frasa rahasiamu. Kunci tetap di device, kami tidak pernah menyimpannya.

02

Aktifkan node cloud

Sekali klik, node mining berjalan di server awan kami. Tidak ada yang dijalankan di device kamu — nol beban CPU & baterai.

03

Pantau dan klaim

Lihat saldo, grafik mining 14 hari, dan node aktifmu kapan saja dari dashboard. Mining jalan terus walau aplikasi ditutup.

Pertanyaan umum

Apakah CLOUD PI gratis?+

Ya — bergabung dan mining dasar gratis. Beberapa fitur premium tersedia di paket berbayar.

Apakah aman menyimpan frasa rahasia di sini?+

Frasa rahasia hanya disimpan di device kamu. Sebagai non-custodial wallet, kami tidak punya akses ke kunci dompetmu.

Apakah HP saya akan boros baterai?+

Tidak. Semua proses mining berjalan di server awan kami, bukan di device kamu. Aplikasi cuma untuk login & memantau — nol beban CPU dan baterai.

Bagaimana kalau saya offline?+

Tetap aman. Mining jalan 24 jam di awan walau HP mati, ditutup, atau tanpa internet. Saat kamu online lagi, saldo terbaru langsung muncul.

Berapa lama sampai bisa menarik π?+

Setelah saldo mencapai ambang minimum jaringan Pi, π siap ditransfer ke wallet utama Pi Network kamu.

Bisa di iPhone dan Android?+

Bisa keduanya, juga di browser desktop modern. Antarmuka responsif untuk layar kecil.

Siap mulai?

Mulai menambang dalam 30 detik.
